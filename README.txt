SUPRA GT — HIGHWAY RUSH

HOW TO PLAY
1. Extract the ZIP file.
2. Open a terminal/command prompt in the extracted folder.
3. Start a local web server:
   Windows / macOS / Linux: python -m http.server 8000
4. Open http://localhost:8000 in a modern browser.

Controls:
- Left / Right arrows or A / D: steer
- W or Up arrow: accelerate
- Space: nitro
- On touchscreens: use the on-screen left, nitro and right buttons

The Toyota Supra GT model is in source/supra.glb. It is loaded locally by the game.
A modern browser and internet connection are needed for the Three.js library CDN.
